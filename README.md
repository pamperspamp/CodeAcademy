# CodeAcademy

Навчальний вебсайт про курси програмування.

## Про проєкт

CodeAcademy — це навчальний сайт, створений для практики HTML, CSS та основ
побудови багатосторінкових вебсайтів. На сайті є опис проєкту, каталог курсів,
детальна інформація про навчальні напрямки та форма зворотного зв’язку.

## Сторінки

- `index.html` — головна сторінка;
- `about.html` — інформація про CodeAcademy;
- `products.html` — каталог курсів;
- `product-info.html` — детальна інформація про курси;
- `contact.html` — форма зворотного зв’язку.

## Навчальні напрямки

- HTML & CSS;
- JavaScript;
- Python;
- Java;
- SQL.

## Технології

- HTML5;
- CSS3;
- базовий JavaScript для перевірки форми;
- SVG-зображення курсів.

## Запуск

Відкрийте `index.html` у браузері або опублікуйте репозиторій через GitHub Pages.

Для реального надсилання форми на GitHub Pages потрібно підключити зовнішній
сервіс обробки форм, наприклад Formspree, і вказати його адресу у властивості
`action` форми в `contact.html`.
